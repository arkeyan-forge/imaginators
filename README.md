# imaginators: Skylanders Imaginators

> **Purpose:** what this repository is until the game's port is merged · **Status:** current · **Tags:** none

The native port of Skylanders Imaginators (Xbox 360 version): the game's configuration, its game-specific runtime code and
its documentation. The port is in progress; its files arrive here when it is merged into the forge.

This repository is a component of the **forge** (`arkeyan-forge/forge`), where it is mounted at `games/imaginators/`.
